# 技能名称：A股舆情多因子量化流水线
## 技能描述
用于开发、迭代、调试基于 Streamlit + AKShare 的A股题材情绪多因子选股原型。
仅用于学习研究、回测验证，**严禁生成任何实盘买卖建议，不预测股价涨跌**；只做标的筛选、行情清洗、舆情情感识别、因子打分、回测评估。

## 强制约束（所有子任务必须遵守）
1. 数据源规则
    - 优先使用 AKShare 免费公开行情；行情必须对齐**前复权**，主动校验前复权错位bug
    - 标的过滤强制开启：ST/*ST、退市预警标的、上市未满60日新股、停牌标的、日均成交额过低低流动性小票，默认剔除
    - 舆情文本来源：股吧标题、财经短资讯；文本需要前置降噪：去广告、去重复灌水内容
2. 舆情NLP输出规范
    调用大模型做情感打分时，**强制输出纯JSON，禁止多余文字**，结构固定：
    ```json
    {
        "sentiment": 0.0,
        "theme": "无",
        "is_noise": false
    }
